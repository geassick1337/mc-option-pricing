# Теория простыми словами

Короткий «словарик» проекта: каждое понятие объяснено так, чтобы его можно было пересказать без формул.

## Рынок и опцион
| Понятие | Простыми словами |
|---|---|
| **Акция** | Маленький кусочек компании. Её цена каждый день меняется. |
| **Колл-опцион** | «Билет с правом»: платишь сейчас, получаешь право (не обязанность) купить акцию через год по заранее оговорённой цене. |
| **Страйк K** | Та самая заранее оговорённая цена покупки. |
| **Срок T** | Через сколько лет билет можно использовать. |
| **Выплата** | `max(S_T − K, 0)`: если акция стала дороже K, выгода равна разнице; если дешевле, билет просто выбрасывается (0). |
| **Волатильность σ** | Насколько сильно «прыгает» цена. Больше σ → цена нервнее. |
| **Безрисковая ставка r** | Процент в «идеально надёжном банке». |
| **Дисконтирование** | Будущие деньги стоят меньше сегодняшних, поэтому выплату умножаем на `e^(−rT)`. |

## Математика
| Понятие | Простыми словами |
|---|---|
| **Броуновское движение** | Зигзагообразное блуждание пылинки в воде: каждый следующий шаг случаен. Так математики моделируют случайные колебания цены. |
| **Геометрическое броуновское движение** | Тот же зигзаг, но для *процентных* изменений цены (цена не уходит ниже нуля). |
| **Нормальное распределение** | «Колокол»: чаще всего значения около середины, редко далеко. `Z ~ N(0,1)` — случайное число из такого колокола. |
| **Математическое ожидание E[·]** | «Среднее по всем возможным вариантам будущего». |
| **Метод Монте-Карло** | Не можем посчитать среднее напрямую → много раз случайно «проживаем» будущее на компьютере и усредняем. Как бросать кубик тысячи раз, чтобы узнать среднее. |
| **N** | Число симуляций (бросков). |
| **Закон больших чисел** | Чем больше бросков, тем ближе среднее к настоящему. |
| **Центральная предельная теорема** | Ошибка среднего ведёт себя как колокол с шириной `σ/√N`. Именно отсюда берётся «1/√N». |
| **Стандартная ошибка** | Типичный размер промаха для одной серии симуляций: `σ_выплаты / √N`. |
| **RMSE** | Корень из среднего квадрата ошибки: «типичная ошибка» по многим повторам. |
| **Доверительный интервал 95%** | Диапазон `оценка ± 1,96·SE`, который в ~95% случаев накрывает истинное значение. |
| **Формула Блэка — Шоулза** | Готовый точный ответ для этой модели: «ответы в конце задачника». |
| **Антитетические переменные** | Хитрость: к каждому случайному `Z` добавляем «зеркальный» `−Z`. Слишком удачные и неудачные сценарии гасят друг друга, и ошибка падает без роста N. |

## Главная идея в одном предложении
> Чтобы ошибка метода Монте-Карло стала в 10 раз меньше, нужно в 100 раз больше симуляций (закон 1/√N).
